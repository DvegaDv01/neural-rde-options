# visualization.py - Plotting Functions

## Overview

This module provides visualization utilities for the Neural RDE framework, enabling plotting of paths, signatures, training progress, implied volatility surfaces, Greeks, and Lévy area analysis.

**Location**: `visualization.py`
**Lines**: 534
**Dependencies**: JAX, NumPy, Matplotlib, neural_rde_options

---

## Functions

### `plot_path_with_signatures(path, step_size, depth, figsize)` (Line 34)

Visualizes a path along with its signature decomposition.

**6-panel figure**:
1. **Log-price path** (top-left): Time series of log_S
2. **Volatility path** (top-right): Time series of σ
3. **Price-Vol phase diagram** (middle-left): Scatter plot colored by time, with Lévy area annotation
4. **Log-signatures heatmap** (middle-right): Heatmap of log-signature components over intervals
5. **Depth-1 components** (bottom-left): Increment time series
6. **Lévy areas per interval** (bottom-right): Bar chart of price-vol Lévy areas

**Parameters**:
- `path`: Array of shape (n_steps, 3) with (time, log_price, vol)
- `step_size`: Interval size for log-signatures
- `depth`: Log-signature depth
- `figsize`: Figure size (default 14x10)

---

### `plot_training_progress(losses, figsize)` (Line 141)

Plots training loss over epochs.

**2-panel figure**:
1. **Linear scale** (left): Standard loss curve
2. **Log scale** (right): Logarithmic loss curve

---

### `plot_implied_vol_surface(model, path, spot, strike_range, tau_range, ...)` (Line 171)

Plots the implied volatility surface generated by the model.

**2-panel figure**:
1. **Contour surface** (left): IV as function of strike and maturity
2. **Smile slices** (right): IV curves by maturity

**Parameters**:
- `model`: Trained NeuralRDE
- `path`: Recent price/vol history
- `spot`: Current spot price
- `strike_range`: (min, max) as fraction of spot
- `tau_range`: (min, max) maturities in years
- `n_strikes`, `n_taus`: Grid resolution
- `implied_vol_atm`: ATM IV for normalization

---

### `plot_greeks_comparison(model, path, spot, strike_range, tau, ...)` (Line 236)

Plots signature Greeks across strikes.

**6-panel figure**:
1. **Theta (Θ)**: Time decay
2. **Delta (Δ)**: Spot sensitivity
3. **Gamma (Γ)**: Convexity
4. **Vega (V)**: Vol sensitivity
5. **Libra (L)**: Lévy area sensitivity (highlighted as "New Greek!")
6. **All Greeks normalized**: Overlay comparison

All plots include zero-lines for reference.

---

### `plot_levy_area_analysis(path, window_size, figsize)` (Line 347)

Analyzes Lévy area patterns in the path.

**4-panel figure**:
1. **Log price colored by Lévy area** (top-left): Path with color indicating local Lévy area
2. **Rolling Lévy area** (top-right): Time series with fill indicating price-leading vs vol-leading
3. **Lévy area distribution** (bottom-left): Histogram with mean annotation
4. **Lévy area vs subsequent return** (bottom-right): Scatter plot with trend line

**Interpretation**:
- Green fill: Lévy area > 0 → Price leads vol
- Red fill: Lévy area < 0 → Vol leads price

---

### `run_visualization_demo()` (Line 441)

Runs a complete visualization demonstration.

**Steps**:
1. Generate sample path (2000 steps, high jump intensity)
2. Plot path with signatures → `path_signatures.png`
3. Plot Lévy area analysis → `levy_area_analysis.png`
4. Train Neural RDE model (30 epochs)
5. Plot training progress → `training_progress.png`
6. Plot Greeks comparison → `greeks_comparison.png`
7. Plot IV surface → `iv_surface.png`

**Output files**:
- `path_signatures.png`
- `levy_area_analysis.png`
- `training_progress.png`
- `greeks_comparison.png`
- `iv_surface.png`

## Usage

```python
from visualization import (
    plot_path_with_signatures,
    plot_levy_area_analysis,
    plot_training_progress,
    plot_greeks_comparison,
    plot_implied_vol_surface,
    run_visualization_demo
)

# Full demo
run_visualization_demo()

# Individual plots
fig1 = plot_path_with_signatures(path, step_size=32, depth=2)
fig2 = plot_levy_area_analysis(path, window_size=50)
fig3 = plot_training_progress(losses)
fig4 = plot_greeks_comparison(model, path, spot)
fig5 = plot_implied_vol_surface(model, path, spot)

plt.show()
```
